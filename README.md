# 💳 Personal Business Card

A simple and stylish personal business card built using **HTML and CSS**. This project features a modern navy blue and pink color scheme, a profile image, personal information, and interactive hover and floating animations.

## ✨ Features

- 🎨 **Modern UI:** Navy blue background with pink accents and white text.
- 👤 **Profile Section:** Displays a profile image and personal details.
- 📱 **Flexbox Layout:** Uses CSS Flexbox to arrange the image and text.
- 🖱️ **Interactive Button:** Includes a hover effect with a color transition and shadow.
- 🎈 **Floating Animation:** Adds subtle up-and-down movement to the entire card.
- 🔄 **Smooth Transitions:** Uses CSS transitions for a polished user experience.
- 🟣 **Rounded Corners:** Rounded card, image, and button for a clean design.

## 🛠️ Technologies Used

- HTML5
- CSS3
  - Flexbox
  - CSS Animations (`@keyframes`)
  - Hover Effects
  - Transitions
  - Box Shadows

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder in VS Code.

3. Make sure the profile image path in your HTML is correct.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
